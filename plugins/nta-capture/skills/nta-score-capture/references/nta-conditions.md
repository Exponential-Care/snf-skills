# PDPM NTA Comorbidity List — Conditions, Points, and MDS Sources

> **Verify before use.** This table reflects the PDPM NTA comorbidity score
> calculation as publicly published by CMS (SNF PPS final rule / PDPM
> calculation worksheet / MDS RAI manual). CMS can revise conditions, point
> values, ICD-10 mappings, and MDS item numbers in any fiscal year, and MDS
> item numbering has changed across versions (e.g., O0100 → O0110,
> K0510 → K0520 in the October 2023 item set). **Always confirm against the
> current MDS RAI manual and the current FY SNF PPS final rule before coding
> or projecting payment.** No dollar rates appear here by design.

Each condition/service a resident qualifies for adds its points **once**.
Sum all points, then map to the tier table at the bottom.

Notes:

- **I8000 rows** qualify only when a listed ICD-10 code from the CMS PDPM
  ICD-10 mapping file for that condition category is entered in I8000 as an
  **active diagnosis** per RAI rules. Use the current FY PDPM ICD-10 mappings
  (published on the CMS PDPM page) to check specific codes.
- **O0110 "post-admit" / "while a resident" items** count only when the
  treatment is performed **while a resident** (column b in the current item
  set) — hospital-only treatment does not qualify. Older documents reference
  O0100 with column 2.
- **Parenteral/IV feeding high vs. low** is distinguished by the proportion of
  total calories and fluid intake received by artificial route; check the
  current RAI manual thresholds (historically: high = 51%+ of calories, or
  26–50% of calories with 501+ cc/day fluid; low = lesser amounts).
- **HIV/AIDS** is the only NTA item drawn from the SNF claim rather than the
  MDS — coordinate with billing so B20 appears on the claim when documented.

## Point-to-tier mapping

| NTA score | Case-mix group (tier) |
|---|---|
| 12+ | NA |
| 9–11 | NB |
| 6–8 | NC |
| 3–5 | ND |
| 1–2 | NE |
| 0 | NF |

Each tier has a CMS-published NTA case-mix index (higher tier = higher CMI;
e.g., in the original PDPM final rule NA ≈ 3.24 down to NF ≈ 0.72). CMIs and
the NTA base rate are updated in each FY SNF PPS final rule — **look up the
current values there; do not rely on these historical figures.** The NTA
per diem is also paid at a **3x adjustment factor on days 1–3** of the stay
and 1.0x on days 4–100.
